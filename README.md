Network Information & Connectivity Analyzer

Project Overview

This is a beginner-level networking project created using Bash scripting in Kali Linux.

Objectives

- Identify IP addresses.
- View MAC addresses.
- Check default gateway.
- Inspect DNS configuration.
- Test network connectivity.
- View listening network sockets.

Technologies Used

- Kali Linux
- Bash Scripting
- Linux Networking Commands

Commands Used

- ip -br a
- ip link
- ip route
- ping
- ss -tuln
- cat /etc/resolv.conf

Learning Outcomes

This project helped me understand Linux networking commands and basic network troubleshooting.
